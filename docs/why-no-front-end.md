# Why this review desk has no front end

The work is comparing records, agreeing the survivor, retaining the reason and checking the next export. A reviewer can do those jobs by asking a coding agent to run the CLI. The database keeps the values and the decisions. Read-only HTML provides a weekly queue, field disagreements and accuracy checks. Branded decision packs can be printed from a browser.

Cloudingo gives operators interactive comparison screens, Salesforce connections and scheduled or real-time operations. This free base works on exports and applies decisions locally. It does not provide those live connections, drag-and-drop mapping, mobile editing, background synchronisation or Salesforce undo. Enterprise DNA builds the operator screen and connections required for a managed version, with a separate cutover test.

A screen is optional for this local review workflow. Claude Code, Codex, OpenCode and Cursor read the same instructions. The agent runs the command and returns the result; no separate app is needed to take an action.
