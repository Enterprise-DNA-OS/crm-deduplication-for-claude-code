# protect

Read the record and obtain the stated reason. Protect it for a correction request or another named concern. Releasing protection needs the operator to confirm that the concern is resolved.

Read docs/cli.md for arguments. Use `node scripts/dedupe.mjs protect` with the required arguments, prefer --json for analysis. Mutations require the operator's --by label. Resolve ambiguous names by showing candidates; never guess. Use the command result as evidence and explain any failure.
