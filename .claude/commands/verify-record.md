# verify-record

Read the record. Record only an accuracy check the operator actually completed, and their next retention review date. Do not claim a date proves legal compliance.

Read docs/cli.md for arguments. Use `node scripts/dedupe.mjs verify-record` with the required arguments, prefer --json for analysis. Mutations require the operator's --by label. Resolve ambiguous names by showing candidates; never guess. Use the command result as evidence and explain any failure.
